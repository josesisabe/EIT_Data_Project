## Work Process / Branching Workflow

- Each team member should create and work on their **own development branch**.
- Commit changes regularly to your branch.
- When your work is ready, **open a pull request (PR)** for review by the other team members.
- **Do not merge directly into `main`**. Merge only after the changes have been **reviewed and approved** by the team.
- Keep `main` clean and stable — it should always represent the **production-ready version** of the project.
